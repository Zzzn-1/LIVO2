# 语义体素地图使用指南

## 概述

本功能将SETIC副线程处理得到的语义信息直接表示在体素地图中，通过颜色编码使语义信息在体素地图中更加明显和直观。

## 主要特性

### 🎨 语义颜色映射
- **16种预定义语义类别**：建筑物、植被、道路、车辆等
- **直观颜色编码**：每种语义类别对应独特的颜色
- **自动主导标签**：体素根据内部点云的语义分布自动确定主要语义类别

### 📊 智能语义统计
- **点数统计**：统计每个体素内各语义类别的点数
- **主导语义**：选择出现次数最多的语义作为体素的主要标签
- **动态更新**：随着新点云的加入，语义信息动态更新

### 🔧 双模式可视化
- **语义模式**：显示带语义颜色的体素地图
- **几何模式**：显示基于几何特征的传统体素地图
- **自动切换**：根据SETIC是否启用自动选择显示模式

## 使用方法

### 1. 启用语义体素地图

在配置文件中设置：
```yaml
# config/avia.yaml 或其他配置文件
publish:
  pub_plane_en: true                  # 启用体素地图发布
  pub_semantic_color_en: true         # 启用语义颜色

common:
  setic_en: 1                         # 启用SETIC处理
  setic_topic: "/setic/image_raw"     # 语义图像话题
```

### 2. 运行系统

```bash
# 启动主程序
roslaunch fast_livo2 mapping.launch

# 语义体素地图将自动发布到以下话题：
# /semantic_planes - 带语义颜色的体素地图
# /planes - 传统几何体素地图
```

### 3. 可视化查看

在RViz中添加MarkerArray显示：

```bash
# 启动RViz
rviz

# 添加以下话题：
# - /semantic_planes (visualization_msgs/MarkerArray)
# - /setic_img (sensor_msgs/Image) - 语义图像
# - /cloud_registered (sensor_msgs/PointCloud2) - 点云
```

### 4. 参数调整

根据需要在 `config/semantic_voxel_config.yaml` 中调整：

```yaml
semantic_processing:
  dominant_label_threshold: 0.3       # 主导标签阈值
  min_semantic_points: 5              # 最少语义点数

visualization:
  semantic_alpha: 0.8                 # 语义体素透明度
  geometric_alpha: 0.4                # 几何体素透明度
```

## 系统架构

```
语义图像输入
     ↓
SETIC副线程处理
     ↓
语义标签分配给点云
     ↓
体素地图更新（含语义信息）
     ↓
语义颜色计算
     ↓
发布带颜色的体素地图
```

## 核心功能说明

### 语义信息统计
```cpp
// 每个体素平面维护语义统计
struct VoxelPlane {
    int semantic_label_;                    // 主要语义标签
    std::map<int, int> semantic_count_;     // 各语义标签的点数统计
    bool has_semantic_;                     // 是否包含语义信息
    
    void addSemanticPoint(int semantic_label);
    void updateDominantSemanticLabel();
};
```

### 颜色映射算法
1. **优先使用语义颜色**：如果体素包含语义信息，使用预定义的语义颜色
2. **回退到几何颜色**：如果无语义信息，使用基于几何特征的颜色
3. **主导语义选择**：选择占比最高的语义类别作为体素颜色

### 实时更新机制
- **异步处理**：语义处理在副线程中进行，不影响主线程性能
- **增量更新**：仅更新包含新语义点的体素
- **统计维护**：动态维护每个体素的语义统计信息

## 性能特点

### ✅ 优势
- **实时性能**：副线程处理，不阻塞主要SLAM算法
- **直观显示**：语义信息直接体现在体素地图颜色上
- **自适应**：根据语义信息可用性自动切换显示模式
- **内存效率**：仅存储必要的语义统计信息

### ⚠️ 注意事项
- **语义质量依赖**：颜色准确性取决于SETIC语义分割质量
- **计算开销**：语义颜色计算会增加一定计算量
- **显示带宽**：彩色体素地图比传统地图需要更多显示带宽

- **行人安全**：洋红色体素标识行人位置
